# One More Call V2

A polished Vite + React emotional story game, designed as an original project inspired by memory-driven narrative games.

## Core improvements

- Rebuilt from scratch as a clean React project.
- No `node_modules` included.
- Render Static Site ready.
- No Vite preview server required in production.
- Fixed-height story panels.
- Scrollable phone conversations.
- Memory fade gameplay.
- Hidden stair note.
- Star-counting gameplay.
- Slow pause scene before the grave scene.
- More emotional dialogue and ambiguous twist.

## Run locally

```bash
npm install
npm run dev
```

## Test production build locally

```bash
npm run build
npm run preview
```

## Render Static Site setup

Recommended Render service type: **Static Site**

- Build Command: `npm install && npm run build`
- Publish Directory: `dist`
- Root Directory: leave blank unless this project is inside a subfolder

Do not deploy this as a Web Service unless you intentionally want to run a server.
